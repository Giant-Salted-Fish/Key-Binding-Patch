# Key Binding Patch — совместимость с Connector

> Форк оригинального мода Key Binding с добавленной совместимостью для Fabric Connector (Fabric → Forge).

## 🎯 Цель форка

Оригинальный мод Key Binding Patch работает только в Forge. Этот форк добавляет возможность использовать мод на **Forge** через [Fabric Connector](https://modrinth.com/mod/connector) (Sinytra Connector).

## ✅ Что сделано

- Добавлена совместимость с Connector
- Мод теперь работает на Forge-сборках через прослойку
- Оригинальный функционал сохранён без изменений

## 📥 Установка

### Для Forge (через Connector)
1. Установи Fabric Connector (Sinytra Connector) в папку `mods/`
2. Установи этот мод туда же
3. Запусти игру

### Для Forge
Работает как обычный Forge-мод (совместимость сохранена)
